# Drone-AI

This simple python script uses a pre-trained YOLO (You Only Look Once) computer vision model to detect faces. When the script is run, a window pops up which you can place above a window where the drone's camera footage is live-streamed, and surrounds detected people with a red rectangle.

Of course, the result depends on two key variables: 
 - **Video quality** : a higher quality onboard camera and a stable connection can improve detection accuracy.
 - **The frames per seconds** : a higher frame rate provides smoother tracking but may require more processing power and network bandwidth.

## Disclaimer

This project is intended for educational and experimental use. Always respect privacy and comply with applicable laws when recording or analyzing video footage.
